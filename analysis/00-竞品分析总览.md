## 3. 核心业务闭环（从字符串与接口名还原）

1. **看车 → 询价 → 联系**：`Brands/GetHotList` → `Cars/carList` / `Cars/NewCars` → `CarsParms/GetCarsParmByCarsId` → `Enquiry/SetEnquiry`（提交询价，提示"提交后您将收到经销商提供的报价方案"）。
2. **买二手 → 卖二手**：`UsedCars/search` → `UsedCars/GetUsedCar` → `UsedCarsReply/AddReply`；卖车 `UsedCars/AddUsedCar` → `UsedCarsAssess/AddUsedCarAssess`（估价）→ `UsedCars/UpUsedCar`（上架）→ `usedCarsDeposit/add` + `UsedCars/wxPay/repay`（信息费）。
3. **租房车 / 共享**：车主入驻 `MerchantAttestation/*` → 上架车辆 `system/information` + `system/rent` → 租客下单 → `FastAttestationPay/WxPay/WxGoToPayDeposit`（押金）→ 订单履约 `system/ownerBill/list`。
4. **社区内容**：`bbsChePost/add`（发帖）→ `bbsChePost/setLike` / `bbsChePostReply/add`（互动）→ `bbsQaQuestion/*`（问答）→ `bbsCheScoreList/*`（榜单）。
5. **账号**：`User/ChangePhone`、`User/SendChangePhoneMsm`、`ThirdLogin/WxAuthLogin`（微信登录）、`AliFace/GetCertifyIdVerify`（人脸实人认证）。

## 6. 逆向风险说明

- 该 APK **未加固**（无 `libjiagu`/`ijiami`），资源与 Dart 层可读，但 **Dart AOT 无 DEX/Java 源码**，无法反编译出 Java 代码——所有页面行为均由"源文件符号 + 界面文案 + 接口名 + 官方截图"三方交叉还原。
- 页面文案在 AOT 中以 UTF-16LE 内联存储，与机器码交织，抽取值存在噪声；文档中的文案均为可读片段，个别词语已按上下文校正。
