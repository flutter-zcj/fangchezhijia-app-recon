# 房车之家 APP 接口清单（静态提取）

> 提取方式：`lib/arm64-v8a/libapp.so` 中的 URL 路径常量聚类（Dart AOT 保留接口名），非抓包。
> 基址：`http://test-fczj-api.fangchezhijia.net.cn`（正式环境应为 `https://...fangchezhijia.net.cn`，路径前缀未知，标【待确认】）。
> 请求方式：Flutter 端统一 `http_request.dart` 封装，推测为 `POST` + JSON body，鉴权头为 token，具体字段【待抓包确认】。
