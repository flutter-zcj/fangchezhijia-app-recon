# 通用 H5 容器页（用例12）

## 基本流程

1. 用户点击协议、活动页、帮助中心等入口，携带 `url`、`title`、`needToken` 等参数进入本页；
    1. 顶部为导航栏：左侧返回、标题（优先取传入 `title`，其次取页面 `<title>`）；
    2. 主体为 WebView，占满导航栏以下区域。
2. 页面加载时展示进度条（0~100%），加载完成后隐藏；
    1. 需要登录态的页面自动在 URL 追加 token 参数（仅白名单域名）；
    2. 域名不在白名单时拒绝加载并提示。
3. WebView 内点击链接：
    1. 同域名内跳转在当前 WebView 内进行，可返回上一页；
    2. 外部域名/唤起 App 的链接先弹二次确认。
4. 返回键处理：WebView 可返回时先回退网页，不可返回时才关闭页面。
5. 支持分享（可选）：点击分享将当前 URL 与标题分享出去。

## 异常情况

1. 加载失败（断网、502、域名解析失败）：
    1. 展示错误页（图标 + 「加载失败，请检查网络」+「重新加载」）；
    2. 点击重试重新加载当前 URL。
2. URL 不在白名单：
    1. 拒绝加载，展示「无法打开该页面」，可返回；
    2. 阻止跳转外部浏览器。
3. 加载超时（30 秒）：
    1. 中止加载并展示错误页。
4. 网页内触发系统能力（拨号、支付、定位）：
    1. 拨号直接调用系统拨号盘；
    2. 支付类走原生支付桥，不在 WebView 内完成。
5. 页面需要登录但未登录：
    1. 先跳登录，登录成功后带 token 重新加载。

## 业务规则

1. 白名单域名：`fangchezhijia.net.cn` 及其子域、`fangchewang.net.cn`；其它域名默认拦截。
2. `needToken=1` 时才追加 token，且仅在 https 下追加，禁止明文传输。
3. 标题优先级：传入 `title` > 网页 `<title>` > 默认「详情」。
4. 进度条在加载完成后 300 毫秒内消失，避免闪烁。
5. 页面缓存策略：不缓存 HTML，仅缓存静态资源，保证活动页内容实时。
6. 分享内容由传入参数决定，未传则使用网页 `<title>` + 当前 URL。
7. 本页不承载登录、支付等敏感操作，敏感流程单独页面实现。

## 页面组件清单与职责划分

| 职责 | 主要责任 | 不应承担的责任 |
| --- | --- | --- |
| H5 页面容器 | 解析参数、组织导航栏与 WebView | 发起业务接口请求 |
| 导航栏 | 标题展示、返回逻辑（先回退网页） | 控制加载进度 |
| WebView 组件 | 渲染网页、进度条、错误态 | 拼接 token、判断白名单 |
| URL 守卫 | 白名单校验、token 追加、外链拦截 | 渲染 UI |
| 桥接服务 | 处理拨号、支付、分享等原生能力 | 修改页面标题 |
