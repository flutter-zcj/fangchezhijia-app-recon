### 竞品差异声明

- 竞品为 **Flutter** 实现，本文档目标为 **uni-app**，因此「代码复用与修改边界」只做同类能力映射，不做跨栈复用判断。
- 竞品的弹窗、吸顶、左滑等交互在 H5 / 小程序端能力不同，文档中已在「依据/风险」列出分端处理要求。
- 竞品文案（如「房车网 APP」「最多可选 3 个话题」）已按原文保留，作为业务规则依据。
