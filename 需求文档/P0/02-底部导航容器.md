# 底部导航容器（用例2）

## 基本流程

1. APP 进入主界面后加载底部导航容器，默认选中「首页」；
    1. 容器一次性初始化 5 个 Tab 页实例并缓存，切换不重建；
    2. 中间「RV 发布」为凸起圆形按钮，不参与 Tab 切换。
2. 用户点击底部 Tab 进行切换；
    1. 首次切换某 Tab 时触发该页 `onShow` 拉取数据；
    2. 再次切回已加载的 Tab 不重复请求，仅下拉可刷新；
    3. 切换时保持各 Tab 的滚动位置与已加载列表。
3. 用户点击中间「RV 发布」按钮；
    1. 未登录 → 拉起登录页，登录后回到发布选择；
    2. 已登录 → 弹出发布选择面板（发动态 / 发布二手车 / 发布车源）。
4. 收到系统推送或点击外部深链进入指定 Tab；
    1. 按深链参数设置默认选中 Tab 并携带业务参数（如帖子 ID）。

## 异常情况

1. 未登录访问需要登录的 Tab（消息、我的）：
    1. 展示登录引导占位页，含「去登录」按钮；
    2. 登录成功后自动回到原 Tab，不丢失来源。
2. Tab 初始化失败（页面注册缺失）：
    1. 该 Tab 显示「页面加载失败，点击重试」，其余 Tab 不受影响。
3. 连续快速点击同一 Tab：
    1. 第二次点击触发该 Tab 列表回到顶部并刷新；
    2. 500 毫秒内重复点击只响应一次。
4. 深链指向不存在的 Tab：
    1. 回落到「首页」，并 toast 提示「页面不存在」。

## 业务规则

1. 底部固定 5 个入口：首页、选车、广场（中间为 RV 发布凸起按钮）、消息、我的。
2. Tab 页实例常驻缓存，切换不得重新创建页面、不得丢失滚动位置。
3. 「消息」Tab 显示未读数角标，未读数为 0 时隐藏；超过 99 显示「99+」。
4. 中间「RV 发布」按钮不切换 Tab，只做发布动作入口；未登录必须拦截登录。
5. 游客可浏览首页、选车、广场；进入消息、我的需登录。
6. 任意 Tab 双击当前 Tab = 回到顶部并下拉刷新。
7. 容器需处理底部安全区（iPhone 底部横条），Tab 高度不压缩内容区。

## 界面描述

页面为容器型界面：内容区占满除底栏外的空间，底栏固定在底部，含 5 个等分入口，中间入口为凸起圆形主色按钮。消息入口右上角可带未读角标。
