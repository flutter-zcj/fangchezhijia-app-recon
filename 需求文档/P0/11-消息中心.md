# 消息中心（用例11）

## 基本流程

1. 用户从底部 Tab「消息」或首页消息图标进入本页；
    1. 顶部为导航栏，标题「消息」，右侧为「全部已读」文字入口；
    2. 顶部横向 Tab：互动消息 / 评论与赞 / 系统通知 / 订单消息，默认「互动消息」。
2. 列表按时间倒序展示会话或通知条目：
    1. 互动类：头像、昵称、动作（赞了你的帖子 / 评论了你的帖子）、内容摘要、时间；
    2. 系统类：图标、标题、正文摘要、时间，未读左侧带红点。
3. 点击条目：
    1. 互动类 → 跳对应帖子详情（评论区定位到该评论）；
    2. 系统类 → 打开 H5 或站内页（按跳转类型）；
    3. 订单类 → 跳订单详情；
    4. 点击即置为已读，未读角标同步递减。
4. 左滑条目可「标记已读 / 删除」（删除仅本地列表移除并上报）。
5. 上拉加载更多，下拉刷新。

## 异常情况

1. 列表接口失败：
    1. 展示错误态与重试；
    2. 已加载内容不清空。
2. 点击条目但目标内容已删除：
    1. toast「内容已删除或不存在」，条目置灰。
3. 「全部已读」接口失败：
    1. 红点状态回滚，toast「操作失败」。
4. 未登录进入：
    1. 展示登录引导，登录后回本页。
5. 分页失败：
    1. 底部提示重试，不清空。

## 业务规则

1. 消息分类四类：互动（关注）、评论与赞、系统通知、订单消息；分类未读数分别计算。
2. 未读红点按分类展示；Tab 上的数字为该分类未读数，0 时隐藏。
3. 进入列表不自动全部已读；仅点击条目或「全部已读」时置读。
4. 「全部已读」只影响当前 Tab，不影响其它分类。
5. 消息保留 90 天，过期由后台清理；前端不做本地清理。
6. 系统通知含跳转类型：无跳转 / 站内页 / H5 / 应用外链接（外部链接需二次确认）。
7. 删除为逻辑删除，服务端保留记录用于审计。

页面为竖版列表：顶部导航栏 + 分类 Tab，主体为消息条目列表（互动类带头像，系统类带图标），支持左滑操作。
