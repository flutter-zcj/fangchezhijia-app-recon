## 逆向结论速览

- **界面 129 个**：100 个 `*_page.dart` + 24 个车主端 `*_index`/`stept` 页 + 5 个公共页
- **模块分布**：social 30 / car 21 / 车主端 24 / mine 15 / used_car 13 / user 6 / zfc 5 / home 3 / search 3
- **接口 60+**：如 `UsedCars/search`、`bbsChePost/add`、`system/rent/getSettings`、`Enquiry/SetEnquiry`
- **业务闭环 5 条**：看车询价、二手买卖、共享租车、社区内容、账号认证
- **技术栈**：Flutter（Dart AOT）+ 高德地图 v10.1 + 支付宝/微信支付 + 阿里云推送/号码认证/OSS

## 方法与边界声明

本项目为**静态取证**：从 `libapp.so` 提取 Dart 源文件符号与 UTF-16LE 界面文案，结合资源、清单解析与接口名聚类还原结构与规则，未做运行时抓包，也未在真机上逐个走查交互。

因此：

1. 页面名称由「源文件名 + 界面文案 + 商店截图」三方推断，存疑项在文档内标注。
2. 字段名、编码枚举、部分文案未在二进制中保留，统一标【待补充】。
3. `需求文档/P0/README.md` 末尾列出 5 项必须回填的待确认事项（Q1–Q5），未回填前不建议直接投产。
